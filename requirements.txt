# Requisitos de Casos Vandalismo
#
# Esta aplicación está hecha en Node.js (no en Python), así que este archivo es
# solo informativo: NO se instala con "pip install -r requirements.txt".
# La lista que usa la instalación de verdad está en package.json.
#
# Para instalar todo:   npm install
# Para trabajar:        npm run dev
# Para publicar:        npm run build   y luego   npm start

# --- Programa necesario en el equipo ---
Node.js >= 22.13        (incluye npm y la base de datos SQLite; no hay que instalar nada más)

# --- Paquetes de la aplicación (los instala "npm install") ---
express ^5.3.0          servidor web y API
react ^19.3.1           pantallas de la aplicación
react-dom ^19.3.1       pantallas de la aplicación
exceljs ^4.4.0          importar el Excel de casos (npm run importar)

# --- Paquetes solo para desarrollo ---
vite ^8.3.7             compila la aplicación web
@vitejs/plugin-react ^6.3.0
concurrently ^10.0.7    arranca servidor y web a la vez con "npm run dev"
